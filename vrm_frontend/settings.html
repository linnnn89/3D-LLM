📁 集中化用户数据保存说明
本软件将所有敏感与个性化资料集中统一保存在该目录下，不污染代码根目录，换机或更新平滑无忧：
  • 🔐 keys.enc：微软 DPAPI 硬件加密的 API Key 保险库
  • ⚙️ user_settings.json：增量保存的用户配置（仅记录与系统默认不一致的改动项）
  • 🧠 memory.sqlite：长期记忆本体、历史对话记录与 FTS5 全文检索索引库
默认系统路径: E:\我的文档\LLM-3D-CHAT (通过 Windows Shell 动态获取)
