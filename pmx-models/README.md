## 二、新角色模型准入验收 Checklist (必须全部满足)

在将新角色置入 `pmx-models/` 之前，必须在 Blender 中使用 `mmd_tools` 或 `Cats Blender Plugin` 校验以下 4 项硬指标：

### 1. 骨骼命名清单（23 核心骨全部到位）
- **根骨与躯干**：`全ての親`、`センター`、`下半身`、`上半身`、`上半身2`、`首`、`頭`
- **双臂**：`左肩`、`左腕`、`左ひじ`、`左手首`；`右肩`、`右腕`、`右ひじ`、`右手首`
- **双腿**：`左足`、`左ひざ`、`左足首`、`左つま先`；`右足`、`右ひざ`、`右足首`、`右つま先`
- **足部 IK**：`左足ＩＫ`、`右足ＩＫ`、`左つま先ＩＫ`、`右つま先ＩＫ`

### 2. 初始姿态 (Rest Pose)
- 模型在 Blender 中必须保存为标准的 **A-Pose**（双臂从水平下压约 40°，掌心微内扣）。
- 严禁保存为 T-Pose 或带有任何非零初始旋转的关键帧姿态。

### 3. 表情形态键 (Morphs)
- 必须包含标准 MMD 眨眼与口型：`まばたき`（眨眼）、`あ`（口型元音 A）、`お`（口型元音 O）、`笑い`（微笑）。

### 4. 蒙皮与权重健康度
- 头部零件（脸部、眼睛、睫毛、眉毛、口腔、舌头）的所有网格顶点**必须归属到 `頭` 骨骼**，严禁未蒙皮或误绑至 Bone 0。
- 游戏抽取的非标扭转骨（如 `ForeTwist`）若无标准 MMD 旋转附与设置，必须在 Blender 中将其权重合并至 `左ひじ` / `右ひじ` 后删除，避免动作运行时前臂塌陷。
